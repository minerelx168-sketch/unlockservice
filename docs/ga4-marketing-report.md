# Marketing reporting — GA4 property 378212303
Use Traffic acquisition with Session source / medium and Session campaign for acquisition, and a funnel exploration for IMEI input → begin_checkout → purchase. Filter web traffic to iunlockmobile.com (and its www alias if used). Verified server events can lack hostname: do not drop those from the transaction reconciliation. Use transaction ID for paid service orders. payment_completed is wallet funding, not a second sale. Do not use sign-up or checkout start as paid conversions.

After rollout, verify actual received event parameters and register these event-scoped custom dimensions only if missing: checkout_click_channel, checkout_utm_source, checkout_utm_medium, checkout_utm_campaign, checkout_utm_content. These describe the checkout snapshot, not GA4 session acquisition. Break purchase and payment_completed down separately by these dimensions. no_click_id is not proof of organic traffic; multiple means conflicting network identifiers. A missing field is unknown. Use gross_margin only when present; purchase value is separate. GA4 is the reporting destination; raw click references, IMEI and email are not reporting dimensions. Ad cost, refunds, and historical backfills are not imported by this change.
For an authorized email lookup, paste the transaction ID into /admin/analytics/transaction. Anonymous orders use their delivery email; a delivery address is not proof of ownership.
