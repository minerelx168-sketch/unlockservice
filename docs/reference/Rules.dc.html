Using this

What actually makes it work.

Copying the hex values gets you a palette, not the feel. Six decisions do most of the work here, and they are all transferable to a completely different brand.

1

Hairlines, never heavy borders

Every edge on the page is 1px, and always one of two values. Structure is drawn with the lightest possible line and then separated by whitespace — which is why a page this dense still reads as calm.

2

Big radii, small padding ratio

Cards run to radius 26–28 with 30px padding — the corner is nearly as large as the inset. That combination is the single most recognisable thing about the look; drop the radius to 8 and it becomes an ordinary dashboard.

3

One shadow, very wide and very soft

0 14px 40px rgba(29,73,82,.08) — a 40px blur at 8% opacity, tinted with the ink colour rather than pure black. It reads as ambient light, not as elevation. There is no shadow ramp; panels either have this one or the larger 80px version, nothing in between.

4

Headlines are huge and tracked tight

76px at −0.058em with line-height 0.98. The negative tracking scales with the size — 52px takes −0.045em, 20px takes −0.025em, body takes none. Get this ramp wrong and everything else looks generic no matter how correct the colours are.

5

Colour is rationed

Long stretches of near-white, then one saturated moment: a blue CTA, a coral secondary, one gradient band. Accents are load-bearing precisely because they are rare. The teal only ever appears as a small uppercase kicker — it is never a fill.

6

Whites are tinted, blacks are not black

Surfaces carry a faint teal cast (#F5FAFA, #EDF8F8) and the darkest text is #0B2F3D. Nothing on the page is #000 or a neutral grey, so the whole thing sits in one temperature.

Keep these

  • One shell width and one gutter for every page — 1180 / 72.
  • Section padding as a constant, not a per-section judgement call.
  • Kicker → headline → lead, in that order, at the top of every block.
  • Body copy in --muted; only headings earn the strong ink.
  • Line-style icons on one grid, in a tinted rounded square.
  • Every token redefined once under a single dark-theme selector.

Where it goes wrong

  • Rounding the measured values to a 4/8px grid. 13, 11, 27, 46, 52 are real numbers here — snapping them flattens the character.
  • Adding a second gradient. One band per page is the budget.
  • Using both the blue and the coral as primary in the same block — the coral is the second action, never the first.
  • Letting card copy set the row height. min-height is what keeps the grids honest.
  • Inverting the palette for dark mode instead of re-pitching it per role.
  • Keeping the 11px uppercase labels at that size on a phone without checking them on glass.
Transfer

Reusing the structure without borrowing the identity.

This is a third-party site, so what travels is the system — the ratios, the rhythm, the component anatomy — while palette, type and marks stay your own. The Openline build in this session is exactly that swap:

What was keptWhat was replaced
1px hairlines, radius 10–28, one wide soft shadow Nothing — geometry is not brand, it is craft.
Section padding constant, 1180px shell, kicker→headline→lead Padding tuned to 104px and a fluid gutter with three breakpoints.
Tinted whites, ink that is never black Cast moved cool teal → warm: #F8F7F3 instead of #F5FAFA.
One primary, one secondary, rationed accents Blue + coral → emerald #0F7A52 + amber #D97B1E.
Display face paired with a plainer body face, tight tracking at scale Google Sans Flex → Bricolage Grotesque + Instrument Sans.
Full dark theme driven by one token block Same mechanism, own values — green-black instead of teal-black.

Foundations, component anatomy and section patterns are on the neighbouring artboards. Values measured from baseimei.com on 21 Aug 2026 and current as of that date only.
