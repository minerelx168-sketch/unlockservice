# Source artboards

These five `.dc.html` files plus `canvas.json` are the design canvas produced in the
**Website design patterns** session, extracted from the published artifact
(`BaseIMEI Design System`) so the work is not lost when the artifact changes.

| File | Artboard |
| --- | --- |
| `Main.dc.html` | Foundations — colour tokens light and dark, type ramp, shape/depth/layout |
| `Components.dc.html` | Component anatomy, light |
| `ComponentsDark.dc.html` | Component anatomy, dark |
| `Patterns.dc.html` | Section patterns — the ten blocks a page is assembled from |
| `Rules.dc.html` | Rules and transfer — what actually makes the system work |
| `canvas.json` | Artboard positions and the canvas annotations |

They are **documentation of a third-party page** (baseimei.com, measured 21 Aug 2026), not assets to
ship. Reuse the ratios and the rhythm; keep palette, type and marks your own — which is what
`docs/design-system.md` and the site itself do.

The files reference a `./support.js` provided by the canvas editor and are not meant to be opened
directly in a browser; read them as source, or open the artifact.
